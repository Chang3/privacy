# AI Compare - 隐私政策

最后更新日期：2026年7月21日

## 1. 数据收集

本扩展程序**不收集、不存储、不传输**任何用户的个人信息、对话内容或浏览数据。

## 2. 本地存储

扩展程序仅使用 Chrome 的 `storage` API 将以下**个性化设置**保存在用户本地浏览器中：
- 对比网格的列数（2-6 列）
- 暗色/日间主题偏好
- 各 AI 模型的显示顺序
- 已启用/禁用的模型列表

**这些数据仅存储在用户本地设备，不会上传到任何远程服务器。**

## 3. 关于登录状态

本扩展通过 iframe 嵌入第三方 AI 网站。用户在这些网站上的登录状态由**浏览器同源 Cookie 机制**自动维护，本扩展程序不读取、不拦截、不处理任何 Cookie 或认证信息。

## 4. 联系我们

如有隐私相关问题，请通过 Chrome 应用商店开发者信息页面联系我们。
